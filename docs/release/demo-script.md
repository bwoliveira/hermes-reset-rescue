# Reset Rescue demo — 75-second shot list

## Prepare

Use a disposable demo profile with at least two accounts and masked, fictional labels such as `e***@e***.com`. Set **dry run** before recording the rehearsal: zero credit spent. Use real reads, scheduling and notices where available, but **do not consume a real credit**. Keep the dry-run indicator `🧪 [Dry run]` visible during the rehearsal and never suggest that a real redemption occurred. Hide real emails, tokens, raw credit IDs, chat IDs and private destinations in every frame.

Add captions using the narration above. Capture actual UI, not mockups. Do not show a successful live redemption during this rehearsal; if a notice does not arrive, cut the shot or state that plainly rather than simulating one.

## What not to show

- A real credit being spent. Every redemption in the recording is either cancelled at the confirmation step or happens in the dry-run profile, and the frame says zero credit spent.
- Full e-mail addresses, real account labels, or any label that is not masked.
- Access tokens, raw credit IDs, Telegram or other chat IDs, and private destinations.
- Other Hermes profiles, the real profile's `auth.json`, or any account outside the demo profile.
- Machine names, IP addresses, and local file paths.
