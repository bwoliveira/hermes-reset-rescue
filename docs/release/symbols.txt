# Reset Rescue — Hermes surfaces that drive the `requires_hermes` floor (T-02)
#
# One entry per line: <id>|<symbol>|<path>|<why the plugin needs it>|<floor>
# `symbol` is passed to `git log -S` (pickaxe: the commit that changed the
# number of occurrences). `path` is required and must narrow the search to the
# files that carry the surface: a whole-tree pickaxe walks every blob in the
# history and takes minutes.
#
# `floor` is `yes` (default when omitted) or `no`. A `no` row is still probed
# and printed, but it cannot raise the floor: use it for a surface the plugin
# only mentions in documentation or that a validator reads, never the runtime.
#
# Order is irrelevant: the probe sorts by the earliest stable tag that contains
# the introducing commit and reports the newest one as the candidate floor.
# Keep this list honest — every line must correspond to a surface the shipped
# code actually uses, or the floor is higher than the truth (catalog rule 14).
